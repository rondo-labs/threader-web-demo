# 球员页

`/players/`（球员入口）和 `/player/<id>/`（一名球员的整个赛季）。版面在 `/prototype/players/` 上定下，2026-11-16 与用户确认（小节左图用原型 C）。数据由 `pipeline/threader_demo/players.py` 生成，和比赛分析在同一次逐场循环里完成。

## 版面

- **`/players/`**：选联赛、位置组、哪些比赛（全部 / 主场 / 客场 / 最近 5 场）、门槛，以及要标出的球队（默认是这个联赛的焦点球队）。左边象限图，右边排名表；点表里一行，图上标出这个人。
  - 象限图：两条轴都可以换成任意一项读数，或年龄、身高、体重、出场时间；每个位置组有自己的默认组合（见下表）。十字线是图上这些人的中位数，四个角只说多少，不分好坏。
  - 搜索：中文名、拼音（全拼或首字母）、Opta 的名字或球衣号码，三个联赛一起找。
- **`/player/<id>/`**：
  - 页头：号码、名字、位置组和各位置的分钟；出场、首发、分钟、进球、助攻；年龄、身高、体重、惯用脚、外援的国籍、加盟时间。两个联赛都踢过的球员，页头可以切换联赛。
  - 和联赛同位置比最突出的 5 项，旁边一张小象限图，标出他在同位置里的位置。
  - 和比赛页一样的六章，最后是比赛记录（每场一行，链到比赛页）。
- **每个小节左图右表，表就是筛选器**：
  - 左图是场上分布：选中的这一项整季画在一张场上，进攻方向向右；超过 240 次先画热区，可以展开成每一次。下面一排按场次的柱子：点一根，场上只画那一场，再点一下回到整季；鼠标停在柱子上，场上那一场的动作亮起来，停在场上的动作上，它那一场的柱子亮起来。
  - 有视频的动作带圈，点开在这个小节的表格上方播放（同比赛页，片段按动作前后几秒截，相隔不到 2 秒的合成一段）。
  - 表的列：每 90 分钟（比率和平均位置照原样）、合计、队内排名、同位置排名、联赛同位置分布、占全队。
  - 他几乎不做、同位置的人也很少做的读数收起来，只写一句有几项。
- **和球队页、比赛页的互动**：球队页「阵容」tab 画出每个位置谁踢了多少分钟，下面是名单；球队页每个小节的表下面写「谁做得最多」，前 3 名，点名字打开他球员页的同一小节；球员页每个小节右上角「全队这一项 →」回到球队页的同一小节。比赛页「谁在场上」和各小节名单的名字后面有 →，打开球员页。

## 读数怎么来

- 比赛页上的每个计数都是一串事件，每个事件有它的球员：球员的读数就是其中他做的那部分，所以球员、球队、比赛三处的数字对得上。
- 不拆到人：控球率、PPDA、对手后场传球成功率、对手从哪打进来、对手拿到球之后、对手传中进禁区、对手禁区内射门（全队或对手的读数），以及传球网络（只统计第一次换人之前；球员改看「个人」里的全场传球）。
- 抢回球之后打成了什么，算抢回的人；丢球之后反抢得怎样，算丢球的人；抢回后的第一脚，算踢这一脚的人。
- 定位球之后的射门算主罚的人：数的是他罚出、之后形成射门的球，所以这几项全队球员加起来比球队的射门数少（一个球可以带出两脚射门）。角球进球、任意球进球不拆。
- 只有球员才有的读数（概览 ·「个人」）：进球（不含乌龙球）、助攻、关键传球（传完队友直接射门，含助攻）、触球、传球（全场所有传球，含传中）、过人和过人成功率、被犯规、黄牌、红牌（含两黄变一红）。门将多一项球门球长传占比。
- 分钟就是比赛页「谁在场上」的分钟：替补从上场算起，被换下或被罚下就停。

## 位置

- 首发的阵型位置来自赛前名单，替补顶的位置来自他上场的换人事件（Opta 限定词 145），变阵时整队重排，被罚下的离场。每个阵型位置换成一个具体位置（左中卫、右边锋……），具体位置再归入六个位置组。
- 同一个 Opta 位置在不同阵型里是不同的活，阵型决定它归哪组：

| 位置组 | 具体位置 |
|---|---|
| 门将 | 门将 |
| 中卫 | 左中卫、中卫、右中卫 |
| 边后卫 | 左后卫、右后卫、左翼卫、右翼卫（三中卫阵型的左右前卫、五后卫阵型的左右后卫） |
| 中场 | 左后腰、后腰、右后腰、左中场、中前卫、右中场（含 4-3-3 和菱形中场的左右前卫）、左前腰、前腰、右前腰（含 3-4-2-1 前锋身后的两人） |
| 边路 | 左前卫、右前卫、左边锋、右边锋（含 4-2-3-1 的左右前腰） |
| 前锋 | 左前锋、中锋、右前锋 |

- 一名球员的位置组是他出场分钟最多的那一组。页面上列出他踢过的具体位置和分钟。

## 排名

- 只和同联赛、同位置组的人比。中超的数据采得更细，抢断尝试、过人、争顶多记很多，所以不跨联赛排名。
- 同位置排名按每 90 分钟，从多到少；比率要有 20 次以上尝试，平均位置要有 10 次以上动作。
- 门槛：出场满这个筛选下可踢分钟的三分之一才参加排名，整季 900、主场或客场 450、最近 5 场 150 分钟。不够门槛的照样有页面，排名一栏写「不排」。`/players/` 可以把门槛调到可踢分钟的六分之一到三分之二。
- 队内排名按合计（谁给球队做得最多）；比率按成功率，同样要 20 次以上尝试。
- 「最近 5 场」是他自己最近出场的 5 场；球队页上的「谁做得最多」跟球队页一样，用球队最近 5 场。
- 赛季中转会的球员：页面挂在他最后效力的球队下；同位置排名按两队合计；队内排名只和现在这支队的人比。
- 占全队：他出场的那些比赛里，全队这一项有多少是他做的。

## 最突出的 5 项

和同位置的人比，排名最靠两头的 5 项（整季，每 90 分钟），一个读数名称只取一次。不参加挑选的：红黄牌、重复别的小节的读数、同位置只有不到 10 人能比的读数、这个位置几乎不做的（中位数每 90 分钟不到 0.15 次）。

## 象限图默认的两条轴

| 位置组 | 横轴 | 纵轴 |
|---|---|---|
| 门将 | 球门球长传占比 | 扑救 / 90 分钟 |
| 中卫 | 传出后场 / 90 分钟 | 防守动作 / 90 分钟 |
| 边后卫 | 传中 / 90 分钟 | 防守动作 / 90 分钟 |
| 中场 | 进入前场 / 90 分钟 | 抢回球权 / 90 分钟 |
| 边路 | 传进禁区 / 90 分钟 | 射门 / 90 分钟 |
| 前锋 | 射门 / 90 分钟 | 前场防守动作 / 90 分钟 |

## 页头的球员资料

- 来自 Opta 2026 赛季的阵容文件（数据湖 `squads/`）：年龄、身高、体重、国籍（只给外援显示）、加盟现在这支队的年月。年龄按这个联赛最后一场比赛的日期算；数据文件里只放年龄，不放出生日期。
- 惯用脚：阵容文件有就用（中超、中甲约一半的球员有，中乙只有 7%）。没有的按射门推：左右脚射门合计至少 8 脚，一只脚占到四分之三写「多用左脚」或「多用右脚」，否则写「两脚都用」；页面上标成虚线下划线，悬停说明是推出来的。
- 之前效力的球队暂不做（要用 2024、2025 赛季的阵容文件）。

## 数据文件

`site-data/players/`：

| 文件 | 内容 | 谁读 |
|---|---|---|
| `<联赛>.json` | 读数清单、每名球员（名字、号码、球队、位置组、各位置分钟、资料）、位置清单、门槛，以及球员在每支队的一段（stint） | `/players/`、`/player/<id>/` |
| `<联赛>-<筛选>.json` | 全部 / 主场 / 客场 / 最近 5 场，每段的分钟、出场、首发和每项读数的合计 | 同上，换筛选时才拿 |
| `p/<id>.json` | 他在每个联赛的每场出场、每项读数的逐场值、被计入的每个动作（位置、结果、比赛时钟、视频时间）、全队逐场的同项计数 | `/player/<id>/` |
| `search.json` | 三个联赛全部球员的名字、拼音、号码、球队 | 搜索框，用到时才拿 |

球队页要的「阵容」（`squad`）和「谁做得最多」（`who`）写在 `site-data/teams/<id>.json` 里，位置清单（`places`）写在 `site-data/leagues/<联赛>.json` 里。
