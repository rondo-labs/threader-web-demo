# 只读，不让搜索引擎收录（原为「只对受邀的人开放」）

演示站没有账号，访问的人只能看，不能写入任何内容；它也不让搜索引擎收录。

最初的决定是只对受邀的人开放：每家俱乐部一个访问凭证，原因有三条，都不在代码里：比赛画面的版权属于转播方或俱乐部；数据湖的约定是只发布分析结果、不发布原始数据，而公开的接口会被整场爬走；在大陆服务器上向公众提供 AI 生成内容可能涉及备案。

2026-11-13 改为不设访问凭证：知道网址的人都能打开，求简单。网站成了一个静态目录，由服务器管理员配好，我们不需要 sudo。仍然不让搜索引擎收录（robots.txt 和页面里的 noindex）。上面三条原因并没有消失，只是这次接受了：比赛视频、每场的分析数据（含该场的事件坐标）任何拿到网址的人都能下载。

**Consequences**: 不提供原始事件下载或批量查询接口，浏览器只拿每个视图需要的数据。上线问答（AI 生成内容）或加更多视频之前，要重新看一遍这三条原因；要恢复访问凭证，需要服务器管理员改 nginx 配置。
