# 公开只读，不设访问凭证，不让搜索引擎收录

演示站没有账号，也不设访问凭证：知道网址就能打开，只能看，不能写入任何内容；页面带 noindex，robots.txt 也不让搜索引擎收录。为了简单：网站就是一个静态目录，由服务器管理员配好，我们不需要 sudo。

这样做接受了三个风险，都不在代码里：比赛画面的版权属于转播方或俱乐部；数据湖的约定是只发布分析结果、不发布原始数据，而比赛视频、每场的分析数据（含该场的事件坐标）任何拿到网址的人都能下载；在大陆服务器上向公众提供 AI 生成内容可能涉及备案。

**Consequences**: 不提供原始事件下载或批量查询接口，浏览器只拿每个视图需要的数据。上线问答（AI 生成内容）或加更多视频之前，要重新看一遍这三个风险；要加访问凭证，需要服务器管理员改 nginx 配置。
